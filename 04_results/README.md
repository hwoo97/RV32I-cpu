## ASIC 합성 (gpdk045)
같은 조건: gpdk045 slow 코너(0.9 V, 125 °C), LEF·QRC, effort high, 합성 주기 = 목표 × 0.8, 메모리 시간 모델 `T_ADDR` 0.5·`T_MEM` 1.0·`T_WB` 1.2·`T_WSU` 0.3 ns, 사용 금지 셀 목록(`syn/common/dont_use.tcl`) 적용 (2026-11-16 다시 합성). 면적 = 셀 면적(µm²), 메모리 제외

| 설계 | 목표 주기 | 셀 면적 | 셀 수 | WNS | 비고 |
|------|----------:|--------:|------:|----:|------|
| 3단계 단일 사이클 코어 `rv32i_core` | **8 ns** | 23,391.4 | 5,840 | 0 | 코어가 낼 수 있는 주기 |
| 3단계 단일 사이클 코어 `rv32i_core` | 8.5 ns | 20,498.1 | 5,192 | 0 | MCU와 같은 주기 (비교 기준) |
| 4단계 MCU `rv32i_mcu` | **8.5 ns** | 24,265.9 | 6,614 | 0 | 코어 대비 +18.4 % (APB 버스·GPIO·TIMER·UART·주소 디코더, 코어 대기). 8 ns는 불만족 |
| 6장 MCU (트랩·인터럽트) `rv32i_mcu` | **8.5 ns** | 30,664.4 | 8,713 | 0 | 4단계 대비 +26.4 % (CSR 5,121.1 — 64비트 카운터 2개) |
| 6장 MCU 칩 (IO 패드 197개) `rv32i_chip` | **13 ns** | 30,531.7 (코어 `u_mcu`) / 2,867,342.7 (패드 포함) | 8,812 | 0 | 메모리가 칩 밖: 한 사이클에 패드 4번 + 메모리 2번. 칩 핀 기준 SDC |

- 4단계 MCU 코어가 3단계 코어와 거의 같은 크기(20,669.8 vs 20,498.1)가 된 것은 `T_WB` 1.2 재배분과 사용 금지 셀 적용 뒤 같은 조건이 되었기 때문. 늘어난 면적(+3,768)의 대부분은 버스·주변장치(3,594)
