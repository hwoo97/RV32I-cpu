# Core-5300 보드 확인
> 목적: 보드 사양과 핀 배치를 정리하고, LED 깜빡임으로 Vivado → 보드 흐름을 확인한다.

| 파일 | 역할 |
|------|------|
| `fpga/common/core5300.xdc` (예정) | 클럭·LED·스위치·버튼 핀 제약 템플릿 |
| `fpga/ch00_blink/` (예정) | LED 깜빡임 설계와 프로젝트 생성 Tcl |

## 1. 보드 자료 확보 (사용자)
보드 매뉴얼·회로도·제조사 마스터 XDC에서 아래 표를 채운다. 공개 자료가 검색되지 않아 학교·제조사에서 받아야 한다.

| 항목 | 값 | 출처 |
|------|----|------|
| 제조사 | | |
| Zynq 칩 품번 (예: XC7Z020-1CLG400C) | | |
| PL 클럭 (핀, 주파수) | | |
| LED (개수, 핀, 켜짐 레벨) | | |
| 스위치·버튼 (개수, 핀) | | |
| 7세그먼트·문자 LCD 유무 | | |
| UART가 PL/PS 중 어디에 연결되는지 | | |
| 영상 출력(VGA/HDMI) 유무·연결 | | |
| PS/2 포트 유무 | | |
| 확장 커넥터(Pmod 등) | | |
| JTAG 연결 방식(USB-JTAG 내장 여부) | | |
| I/O 전압(IOSTANDARD, 예: LVCMOS33) | | |

## 2. 절차 (자료 확보 후)
1. Vivado에서 칩 품번으로 RTL 프로젝트 생성
2. XDC 템플릿에 클럭·LED 핀 입력
3. 클럭을 나눠 LED 하나를 1 Hz로 깜빡이는 설계 작성 (직접 입력)
4. 합성 → 구현 → 비트스트림 → Hardware Manager로 다운로드
5. CPU 장에서 쓸 ILA(내부 신호 관찰)를 한 번 붙여 본다

## 3. 통과 기준
| # | 항목 | 통과 기준 |
|---|------|-----------|
| 1 | 보드 자료 | 1절 표 모두 채움 |
| 2 | 비트스트림 | 타이밍 위반 없이 생성 |
| 3 | 보드 동작 | LED가 약 1초 주기로 깜빡임 |
| 4 | ILA | 카운터 값이 ILA 파형에 보임 |
