# Xcelium 확인 (Linux 서버)
> 목적: 주 시뮬레이터 Xcelium으로 자가 검사 테스트벤치를 실행하고 PASS/FAIL을 판정한다.

| 파일 | 역할 |
|------|------|
| `sim/run_xrun.sh` (예정) | `xrun` 실행 + 로그에서 PASS/FAIL 판정 (서버에서 처음 실행할 때 함께 만든다) |
| [`sim/run_sim.py`](../../sim/run_sim.py) | 이 PC의 xsim으로 빠르게 확인할 때 쓰는 보조 스크립트 |

## 1. 준비
- 학교 서버: 로그인 시 환경 자동 설정, Xcelium 22.03-s012
- 로그인 셸이 **csh** → 판정 스크립트는 첫 줄 `#!/bin/bash`로 작성해 bash로 실행 (터미널에서 직접 치는 명령만 csh 문법)

## 2. 절차
1. 2단계에서 이 PC의 xsim으로 시험한 4비트 카운터와 테스트벤치를 서버로 가져와 실행
```bash
xrun -64bit cnt.v cnt_tb.v
```
2. 파형이 필요하면 SimVision
```bash
xrun -64bit -access +rwc -gui cnt.v cnt_tb.v
```
3. 일부러 기댓값을 틀리게 해서 FAIL이 출력되는지 확인
4. 판정 스크립트(`sim/run_xrun.sh`)를 만들어 `xrun.log`에서 `PASS`/`FAIL`을 찾아 종료 코드로 돌려주게 한다

## 3. 통과 기준
| # | 항목 | 통과 기준 |
|---|------|-----------|
| 1 | 환경 | `xrun -version` 출력 |
| 2 | 시뮬레이션 | 샘플 테스트벤치 PASS, 틀린 기댓값 FAIL |
| 3 | 파형 | SimVision으로 파형 확인 |
| 4 | 판정 스크립트 | PASS면 종료 코드 0, FAIL·타임아웃이면 1 |
